# 📊 Customer Churn Analysis

## Project Overview

This project explores customer churn data to identify the key factors that influence customer retention. The analysis includes data cleaning, exploratory data analysis (EDA), SQL queries, and data visualizations using Python.

## Tools & Technologies

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- SQLite
- Jupyter Notebook

## Project Files

- `customer_churn_analysis.ipynb` – Complete analysis notebook
- `customer_churn.csv` – Cleaned dataset used for analysis
